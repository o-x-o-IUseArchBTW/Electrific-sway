# electrific-Sway

A Sway rice built around a black and cyan color scheme. I wanted the colors to feel consistent all the way around.

## What's included

- **Sway** — window manager
- **Waybar** — status bar
- **SwayNC** — notification center
- **Wofi** — application launcher
- **Zsh** — shell
- **Starship** — shell prompt

## Color palette

| Color | Hex |
|---|---|
| Black | `#000101` |
| Electric cyan | `#00d9ff` |
| Dark cyan | `#006b78` |
| Text | `#d5e5e9` |

## Setup

These are my personal configs. Depending on your setup, you may need to install the required programs, fonts, or plugins and adjust some paths.

To setup Zsh run chsh -s /bin/zsh 

Back up your existing configs before replacing them.
